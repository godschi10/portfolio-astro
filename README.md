# portfolio-astro

Personal portfolio site for Gwill Chijioke, built with Astro.

## Status

**v0.1.0** — Header and hero mockup only. Draft copy. Design language provisional.

## Stack

- Astro 5 (static output)
- Vanilla CSS (inline, responsive)
- No frameworks, no dependencies beyond Astro

## Structure

```
├── astro.config.mjs
├── docs/
│   └── DESIGN-LANGUAGE.md
├── package.json
├── README.md
├── CHANGELOG.md
└── src/
    └── pages/
        └── index.astro
```

## Design Notes

- Ivory / ink / violet palette — editorial, typographic, spare
- Straight geometry: no border-radius pills, no gradients
- Responsive at 360px, 768px, 1280px breakpoints
- `prefers-color-scheme` dark mode
- Single h1, skip link, focus rings, labelled pending sections
- GC letterform composition is a design study — not a client project
